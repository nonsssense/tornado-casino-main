# Кампании и будущая админка (язык продукта)

## Зачем кампании

Чтобы маркетинг запускал акции **без** постоянных правок кода: даты, аудитория, награда, лимиты бюджета.

## Что сделано технически

Появился «движок учёта кампаний»: можно хранить акцию, прогресс игрока, статусы.  
Он **уже может отслеживать** события (регистрация, депозит, ставки), если кампанию завели в системе.

## Чего ещё нет для маркетинга

| Нужно маркетологу | Сейчас |
|---|---|
| Форма «создать акцию» в админке | Нет (*Planned*) |
| Выбор страны / VIP / сегмента | Нет (*Planned*) |
| Автовыдача награды из кампании | Нет — награды по-прежнему старые бонус/реферал-правила |
| Страница «Акции» у игрока | Нет (*Planned*) |
| Промокоды / миссии / лидерборды как акции | Planned |

## Как работать сегодня

Новые офферы депозита и реф.условия = согласование с разработкой + изменение конфигурации + релиз.

## Как будет (цель)

```
Маркетинг заполняет форму кампании
  → проверка
  → кампания активна
  → игрок видит и проходит
  → система считает прогресс
  → награда (когда подключим)
```

Пока средние шаги «форма / выдача из кампании» — **Future extension**.
