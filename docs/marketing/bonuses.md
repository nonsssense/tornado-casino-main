# Бонусы (язык продукта)

## Есть сейчас: бонус на первые депозиты

Игрок при пополнении от минимальной суммы может получить **бонусные средства** (% от депозита, с потолком).

Условия в общих чертах:

- действует на **первые три** пополнения (разный % на 1-е / 2-е / 3-е);
- бонус нужно **отыграть** в разрешённых играх;
- есть лимит ставки и лимит выигрыша с бонуса;
- Crash **не** принимает бонусный баланс (только «живые» деньги);
- бонус **нельзя вывести**, пока не выполнен отыгрыш / правила.

Точные цифры — в коммерческой спецификации / конфиге релиза (их задаёт продукт вместе с разработкой).

## Что видит игрок

- выбор предложения на экране депозита;
- отдельная сумма «бонус» в кошельке.

Полоска прогресса отыгрыша в интерфейсе пока слабая (**доработать UX**).
