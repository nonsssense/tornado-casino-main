# Возможности платформы (для маркетинга)

## Что такое Tornado

Игровое приложение в Telegram: пополнение криптой, три игры, бонусы на депозит, реферальная программа.

## Есть сейчас

| Возможность | Коротко |
|---|---|
| Игры | Dice, Plinko, Crash |
| Депозит / вывод | Крипто через платёжного провайдера |
| Бонус на 1–3 депозит | Процент к депозиту, с отыгрышем и лимитами |
| Реферал | Бонус за квалифицированный первый депозит друга + доля с его игры |
| Баланс бонуса отдельно | Бонус нельзя вывести, пока не отыгран |
| Настройки | Звук / вибрация |
