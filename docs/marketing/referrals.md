# Реферальная программа (язык продукта)

## Есть сейчас (клиентская)

Игрок приглашает друга ссылкой из Telegram.

1. Друг регистрируется по ссылке.  
2. Когда друг делает **квалифицированный первый депозит**, пригласивший может получить **фиксированный бонус** (с дневным лимитом на злоупотребления).  
3. С **реальных** ставок друга в Dice/Plinko пригласивший получает **долю** (процент растёт с числом квалифицированных друзей — Bronze / Silver / Gold).  
4. Начисления проходят период удержания, затем их можно забрать на баланс.

Crash в эту «долю с игры» **пока не входит**.

## Чего нет в приложении сейчас

- удобного экрана «мои рефералы / забрать» (меню есть, раздел не доведён);
- отдельной **affiliate**-программы для вебмастеров с особыми условиями.
