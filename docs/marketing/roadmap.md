# Roadmap возможностей (не обещать как готовое)

Всё ниже — **Planned / Future**, если не указано иное.

| Идея | Зачем бизнесу | Зависимость |
|---|---|---|
| Admin Panel кампаний | Акции без деплоя | Campaign Engine + UI + права |
| Сегменты (страна, VIP, активность) | Точечные офферы | RuleEvaluator + данные игрока |
| Промокоды | Перфоманс / инфлюенсеры | Новая сущность + антифрод |
| Кэшбек / lossback | Удержание | Периоды, ledger, бюджет |
| Фрибеты / фриспины | Ретеншн | Открыть продукт + лимиты |
| VIP уровни | Лояльность | Сегменты + привилегии |
| Турниры / лидерборды | Активность | Отдельный домен |
| Миссии | Ежедневный заход | Progress + UI |
| Push / in-app campaigns | Реактивация | Каналы Telegram + правила |
| A/B тесты офферов | Оптимизация | Bucketing в сегментации |
| Affiliate программа | Рост трафика | Отдельные тиры/кабинеты |
| Crash в реф.доле | Честность партнёрам | Доработка хука Crash |

## Что уже можно опираться в коммуникациях

- Три игры в Telegram.  
- Крипто-депозит/вывод.  
- Бонус на первые депозиты с отыгрышем.  
- Клиентская рефералка (с оговорками по UI и Crash).

Цифры (% / $) брать только из актуального релизного конфига / спеки, не из черновиков research.
